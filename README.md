# calcom-mailerlite-webhook

**Archived October 12, 2026. Not in use.**

This Vercel function was built to add new Cal.com bookings to the MailerLite "Booked Call" group. It never went live for real bookings because Cal.com's webhook toggle would not stay enabled.

The job is now handled by the Zapier Zap "Cal.com Booking to Booked Call Group" (free tier, live since October 8, 2026).

If Zapier ever stops working or volume outgrows the free tier, this code is a working starting point. See REPAIR-NOTES.md for where debugging left off.
